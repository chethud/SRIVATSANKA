# Srivatsanka Events and Services — brand assets

Built from your official logo artwork. The **infinity-leaf icon** is preserved exactly from the source file; typography is flat premium serif (no outlines, glow, or shadows).

| File | Use |
|------|-----|
| `icon-symbol.png` | Extracted icon only (transparent) |
| `logo-sidebar.svg` | **Vertical** — dashboard sidebar (280×180) |
| `logo-horizontal.svg` | **Horizontal** — icon left, text right |
| `logo-icon.svg` | **Favicon** — icon only |
| `logo.svg` | Same as horizontal |
| `logo-sidebar.png` | Vertical PNG (1120×720, ~4K sidebar) |
| `logo-horizontal-4k.png` | Horizontal PNG (3840×800) |
| `logo-horizontal.png` | Horizontal PNG (960×200) |
| `logo-icon.png` | Favicon PNG (512×512) |

**Colors:** Emerald `#0B6B3A` · Fresh `#7AC943` (in icon artwork)  
**Fonts (SVG text):** Playfair Display + Cormorant Garamond  

**Rebuild after updating source logo:**

```bash
python website/scripts/build_logo_assets.py
```
